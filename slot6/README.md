# PRM393 - Slot 6: Student List Interaction App

Ứng dụng Flutter hiển thị danh sách sinh viên bằng `ListView.builder` và `Card` + `ListTile`, cho phép người dùng tap chọn/đánh dấu trạng thái trực tiếp trên UI.

## Cấu trúc dự án
- `lib/models/student.dart`: Model dữ liệu sinh viên.
- `lib/widgets/student_card.dart`: Widget hiển thị từng item sinh viên.
- `lib/screens/home_screen.dart`: Màn hình danh sách sinh viên với tương tác tap.
- `lib/main.dart`: Cấu hình app gốc.
